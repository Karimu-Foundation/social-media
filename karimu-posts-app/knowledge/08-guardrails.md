# 08 — Guardrails & Pre-Delivery Checklist

Run this before handing over any content. If a line fails, fix it — don't ship it
with a caveat.

## Strategy
- [ ] The post has **exactly one** CTA, and it is the right one for the funnel stage.
- [ ] On Instagram/Facebook, the CTA is **not** "donate" — unless this is an
      explicitly requested Fundraising Support post.
- [ ] The post belongs to one of the seven content pillars.
- [ ] It is written for a reachable persona (Compassionate Contributor, Global
      Citizen, Adventure Philanthropist), not for an existing major donor.
- [ ] If it's the monthly newsletter push, it lands *before* the newsletter send.

## Truth
- [ ] Every number appears in `07-impact-facts.md` — or is flagged `[VERIFY: …]`.
- [ ] Every ⚠ figure used states its cohort, ward and year.
- [ ] No invented quote, name, date, place or asset.
- [ ] Every named person is already public in Karimu's channels, or the user
      confirmed consent.
- [ ] **Checked the Karimu Pictures shared drive** (`claude/10-photo-video-library.md`
      for the link, usage rules and folder map) for existing footage matching
      the ward/project/year **before** writing `ASSET NEEDED:`. Assets are
      named explicitly (drive folder path or existing file names), or an
      `ASSET NEEDED:` line describes the shot and the folder it should land in.

## Dignity
- [ ] No "save / rescue / helpless / needy / the poor / third world."
- [ ] The community is the **subject** of its sentences, not the object.
- [ ] Tanzanian people are named and titled, not anonymous "villagers."
- [ ] No child is identified by full name + school + location together.
- [ ] Hardship is framed as a **starting point**, never as spectacle.

## Length  ⚠ the most common failure
- [ ] Caption is within the ceiling in `04-voice-and-tone.md` — **count the words.**
- [ ] No slide has both a body paragraph and a bullet list.
- [ ] No slide carries more than 3 bullets.
- [ ] Every bullet is ≤14 words; every headline ≤8; every script line ≤10.
- [ ] You cut the draft by a third before delivering. If you did not, do it now.

## Craft
- [ ] Could this be a **Before/After** or a **Data card**? If yes, it probably should be.
- [ ] Story **and** number are both present.
- [ ] First line works as a standalone hook (IG cuts at ~125 chars; LinkedIn at ~2 lines).
- [ ] Channel-appropriate length, emoji count, hashtags.
- [ ] No "click the link below" on Instagram.
- [ ] Alt text written.
- [ ] US English, no typos, no double spaces.
- [ ] Visual direction is specific enough that a designer could execute it without
      asking a follow-up question — and names a real drive folder wherever one
      exists (see `claude/10-photo-video-library.md`).

## Brand
- [ ] Only Brand Manual colors.
- [ ] IM Fell for display, Lexend Peta for descriptors/labels.
- [ ] Background off-white `#FEFFF8`, not pure white.
- [ ] Logo has clear space, is not recolored or placed on a busy image.
- [ ] YouTube thumbnail: **face, no text.**

## Escalate to a human — do not decide alone
- Anything touching politics, government criticism, or religion.
- Response to negative press, a complaint, or a public accusation.
- New financial claims or new efficiency percentages.
- Content featuring a person for the first time.
- Anything about a specific donor's gift.
- Emergency, death, or crisis in a community Karimu serves.
